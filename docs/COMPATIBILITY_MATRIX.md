# Compatibility matrix

## Python versions

| Python | Status |
|--------|--------|
| 3.11 | Supported |
| 3.12 | Supported |
| 3.13 | Supported (primary) |
| 3.14+ | Untested |

## Operating systems

| OS | Status |
|----|--------|
| Ubuntu 22.04+ | Supported (CI primary) |
| macOS 13+ | Supported (development) |
| Windows 11 | Supported |
| Alpine Linux | Supported (Docker) |

## CI platforms

| Platform | Status |
|----------|--------|
| GitHub Actions | Primary, fully tested |
| GitLab CI | Supported via CLI |
| Jenkins | Supported via CLI |
| Azure DevOps | Supported via CLI |
| CircleCI | Supported via CLI |
