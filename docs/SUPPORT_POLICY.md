# Support policy

## Community edition

- Community support via GitHub Issues.
- Bug fixes for the latest release only.
- No guaranteed response time.

## Professional edition

- Email support with 48-hour response time.
- Bug fixes for current and previous release.
- Security patches for critical issues.

## Enterprise edition

- Dedicated support with SLA (see licence agreement).
- Bug fixes for current and two previous releases.
- Priority security patches.
- Configuration and deployment assistance.

## Security vulnerabilities

Report security vulnerabilities via the responsible disclosure process
described in `SECURITY.md`. Do not file public issues for security
vulnerabilities.

## Incident response

See [docs/INCIDENT_RESPONSE.md](INCIDENT_RESPONSE.md) for the
incident response process.
