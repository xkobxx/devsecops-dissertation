# Standard policy packs

These ten versioned policies are starting points, not universal release rules.
Review their thresholds, evidence requirements, repository overrides, and
default actions against your threat model before deployment. Each directory
contains a policy, documented intent, a runtime-context fixture, and explicit
expectations exercised by the Trust Gate test suite.

Automated evidence and use of any pack does not guarantee compliance with a
law, regulation, contract, OWASP ASVS, NIST SSDF, or another assurance
framework. Compliance assessment requires organisation-specific scope,
controls, evidence, and qualified human review.
