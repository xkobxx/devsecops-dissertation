# Container security

This pack combines known exploitation, deployment reachability, fix
availability, severity, and scanner health. Apply it only to findings for images
or workloads whose deployment evidence is trustworthy.

The included test exercises the known-exploited reachable rule. Add repository
overrides for image provenance, runtime tier, and deployment criticality.

Automated evidence does not guarantee compliance with a container-security
benchmark or that an image is secure. Use of this policy does not change that
limitation. Runtime controls, provenance checks, and human review remain necessary.
