# Financial services

This pack prioritises injection risks on critical production assets, known
exploitation in production, and confirmed reachable high findings. It is an
example risk posture, not a mapping to any particular regulator or jurisdiction.

The included test exercises the critical-asset injection rule. Adapt repository,
asset, evidence, and remediation requirements to the service's actual risk.

Automated evidence does not guarantee compliance with financial-services laws,
regulations, or contracts. Use of this policy does not change that limitation.
Qualified legal, risk, and security review remain necessary.
