# High-assurance baseline

This conservative baseline blocks credible high or critical production findings,
surfaces degraded scanner evidence as insufficient, and prevents release for
confirmed medium findings. Its default requires a remediation SLA.

The included test exercises the production high-severity rule. Teams should set
scanner requirements and assurance thresholds from their own safety case.

Automated evidence does not guarantee compliance or a high-assurance system.
Use of this policy does not change that limitation. Independent assurance and
qualified human review remain necessary.
