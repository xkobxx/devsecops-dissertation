# NIST SSDF-aligned

This pack reflects selected secure-development themes: prevent new serious
findings, make incomplete verification visible, and remediate serious findings
when a fix exists. It is not a complete implementation of NIST SSDF practices.

The included test exercises the new high finding rule. Document the SSDF version,
practice mapping, evidence owners, and non-scanner controls used by your program.

Automated evidence does not guarantee compliance or conformance with NIST SSDF.
Use of this policy does not change that limitation. A complete,
organisation-specific assessment and qualified human review remain necessary.
