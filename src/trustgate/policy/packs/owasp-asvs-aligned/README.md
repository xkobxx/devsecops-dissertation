# OWASP ASVS-aligned

This pack uses selected CWE families to represent injection, path traversal,
server-side request forgery, authentication, and access-control themes relevant
to OWASP ASVS. It is not an exhaustive ASVS requirement map or verification
method.

The included test exercises the high-severity injection rule. Map findings to
the exact ASVS version, application level, and verification evidence you adopt.

Automated evidence does not guarantee compliance or conformance with OWASP ASVS.
Use of this policy does not change that limitation. A complete, version-specific
assessment and qualified human review remain necessary.
