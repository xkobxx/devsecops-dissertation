# Public-sector supplier

This pack blocks known exploitation and new high or critical findings, then
requires a fix for reachable findings when one is available. Procurement and
contract requirements should be represented as explicit local overrides.

The included test exercises the known-exploited rule. Review the baseline with
the contracting authority and the supplier's risk owners before use.

Automated evidence does not guarantee compliance with public procurement,
government-security, or contractual requirements. Use of this policy does not
change that limitation. Qualified human assurance remains necessary.
