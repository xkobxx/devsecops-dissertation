# Startup baseline

Use this pack as a pragmatic starting point for a small team: it blocks known
exploitation and credible critical findings, requires reachable high findings
to be fixed before release, and schedules fixable medium findings.

The included context and expectation verify the critical-finding rule against
the shared saved scan. Tune the confidence threshold and default action for the
team's evidence coverage and release process.

Automated evidence does not guarantee compliance or that a release is secure.
Use of this policy does not change that limitation. Human review and an
organisation-specific threat model remain necessary.
