# Supply-chain security

This pack combines known exploitation, EPSS, reachability, fix availability,
and dependency-scanner health. It addresses finding decisions only; provenance,
build integrity, signing, and supplier controls require separate evidence.

The included test exercises the exploited reachable dependency rule. Tailor the
EPSS threshold, deployment scope, and required scanner set to your environment.

Automated evidence does not guarantee compliance with a supply-chain framework
or complete dependency security. Use of this policy does not change that
limitation. Provenance controls and qualified human review remain necessary.
